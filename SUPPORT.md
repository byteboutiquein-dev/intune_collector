# Support

Use public repository issues for reproducible bugs, documentation corrections,
and feature proposals that contain no customer or security-sensitive data.

Do not post endpoint logs, tenant exports, credentials, enrollment tokens,
email addresses, or device identifiers. Use synthetic data when demonstrating a
normalization problem.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md). SentVora SaaS
account, billing, retention, and service incidents are outside this source
repository and must use the support channel provided in the SentVora product.
