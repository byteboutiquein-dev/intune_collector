# SentVora Windows Evidence Collector 2.10.1 Preview 1

## Release classification

This is an **unsigned evaluation release** for the SignPath Foundation review
process. It is not approved for customer or production deployment.

Use it only on disposable test endpoints with the explicit
`-AllowUnsignedLabBuild` installation override. Do not distribute this build
as trusted SentVora software.

## Source and build provenance

- Repository: <https://github.com/byteboutiquein-dev/intune_collector>
- Version: `2.10.1`
- Preview tag: `v2.10.1-preview.1`
- Build system: GitHub Actions on `windows-2022`
- Build workflow: `.github/workflows/ci.yml`

The tag workflow validates the public-source boundary, runs the native .NET
tests and lifecycle contract tests, and creates a self-contained Windows x64
ZIP plus a SHA-256 checksum file. The GitHub Actions artifact is explicitly
named as an unsigned lab collector.

## Changes since 2.10.0 Preview 1

These fixes make log collection, enrollment and state protection reliable
(#6).

- **No skipped or split log lines.** A saved cursor always ends on a complete
  line. A full batch no longer skips lines the reader had buffered ahead, and
  a half-written line waits for the next poll instead of being read in two
  pieces.
- **Rotated logs are drained first.** When the Intune Management Extension
  renames a log, the unread lines in the rotated file are sent before the new
  file is read. Files are identified by their NTFS file index, which survives
  a rename and is never inherited by a replacement file. Cursors saved by
  2.10.0 are still matched after the update.
- **Enrollment no longer stops the service.** Without a token, the service
  checks for one every minute. An unreachable server is retried from 30
  seconds, doubling up to 15 minutes. A refused token is retried every 15
  minutes so a replacement can be supplied.
- **A revoked credential backs off.** After a 401 or 403, the service retries
  every 15 minutes and logs that `Reenroll-Collector.ps1` is needed. Other
  upload failures back off the same way.
- **The service enforces its state directory ACL.** On start, and whenever it
  recreates the directory, the service restricts
  `ProgramData\IntuneReliability\Collector` to SYSTEM and Administrators.
- **Lines without evidence advance the cursor without an upload.** They are
  no longer re-read on every poll. Cursors past evidence still advance only
  after the server accepts the batch.

There are no new log sources, uploaded fields, endpoints or privileges.

## Included behavior

- Runs as a read-only Windows service.
- Reads only allow-listed Microsoft Intune Management Extension log files.
- Normalizes bounded application lifecycle evidence locally.
- Uploads structured events over administrator-configured outbound HTTPS.
- Protects the endpoint credential with machine-scoped Windows DPAPI.
- Advances cursors past evidence only after the server accepts an idempotent
  batch.
- Supports credential rotation, re-enrollment, update, status inspection, and
  complete uninstallation.

The collector has no remote command channel and cannot change Intune policy,
clear GRS, retry or install applications, run downloaded commands, or restart
the endpoint.

## Evaluation verification

After downloading the workflow artifact, verify the package checksum before
extracting it:

```powershell
Get-FileHash .\SentVora-Collector-2.10.1-win-x64.zip -Algorithm SHA256
Get-Content .\SentVora-Collector-2.10.1-win-x64.zip.sha256
```

The values must match exactly. Installation requires an administrator to
acknowledge the privacy notice and deliberately opt into the unsigned lab
override:

```powershell
.\Install-Collector.ps1 `
    -ApiBaseUrl "https://YOUR-SENTVORA-HOST/" `
    -AllowUnsignedLabBuild
```

To update an endpoint running the unsigned 2.10.0 preview in place, run the
update script from the extracted 2.10.1 package. The credential and cursors
are kept:

```powershell
.\Update-Collector.ps1 -AllowUnsignedLabBuild
```

Never place an enrollment token in a command line, script, release asset, or
issue. The installer requests it interactively as a one-time secret.
