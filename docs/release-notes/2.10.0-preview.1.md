# SentVora Windows Evidence Collector 2.10.0 Preview 1

## Release classification

This is an **unsigned evaluation release** for the SignPath Foundation review
process. It is not approved for customer or production deployment.

Use it only on disposable test endpoints with the explicit
`-AllowUnsignedLabBuild` installation override. Do not distribute this build
as trusted SentVora software.

## Source and build provenance

- Repository: <https://github.com/byteboutiquein-dev/intune_collector>
- Version: `2.10.0`
- Preview tag: `v2.10.0-preview.1`
- Build system: GitHub Actions on `windows-2022`
- Build workflow: `.github/workflows/ci.yml`
- License: Apache-2.0

The tag workflow validates the public-source boundary, runs the native .NET
tests and lifecycle contract tests, and creates a self-contained Windows x64
ZIP plus a SHA-256 checksum file. The GitHub Actions artifact is explicitly
named as an unsigned lab collector.

## Included behavior

- Runs as a read-only Windows service.
- Reads only allow-listed Microsoft Intune Management Extension log files.
- Normalizes bounded application lifecycle evidence locally.
- Uploads structured events over administrator-configured outbound HTTPS.
- Protects the endpoint credential with machine-scoped Windows DPAPI.
- Advances cursors only after the server accepts an idempotent batch.
- Supports credential rotation, re-enrollment, update, status inspection, and
  complete uninstallation.

The collector has no remote command channel and cannot change Intune policy,
clear GRS, retry or install applications, run downloaded commands, or restart
the endpoint.

## Evaluation verification

After downloading the workflow artifact, verify the package checksum before
extracting it:

```powershell
Get-FileHash .\SentVora-Collector-2.10.0-win-x64.zip -Algorithm SHA256
Get-Content .\SentVora-Collector-2.10.0-win-x64.zip.sha256
```

The values must match exactly. Installation requires an administrator to
acknowledge the privacy notice and deliberately opt into the unsigned lab
override:

```powershell
.\Install-Collector.ps1 `
    -ApiBaseUrl "https://YOUR-SENTVORA-HOST/" `
    -AllowUnsignedLabBuild
```

Never place an enrollment token in a command line, script, release asset, or
issue. The installer requests it interactively as a one-time secret.

Production package-signing controls are implemented, but this preview is not
signed. SignPath Foundation acceptance and the first trusted, timestamped
release remain pending.
